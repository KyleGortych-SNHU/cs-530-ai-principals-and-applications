# Module 5 2D game using python and Pygame library

## Overview

In the past, developers relied on search engines and documentation to learn how to use new software libraries. Today, AI
tools like GitHub Copilot can streamline this process by acting as an intelligent assistant that helps generate,
explain, and debug code based on natural language input. In this activity, you will use GitHub Copilot to build a simple
2D game using the Python Pygame library. You are not expected to have prior experience with Pygame; your goal is to
communicate effectively with the AI tool and allow it to guide the development process based on the functional
requirements provided. By using GitHub Copilot as your coding partner, you will learn how to frame prompts, iterate
based on output, and troubleshoot common issues—critical skills for integrating AI into real-world software workflows.

## Scenario

You have just joined a small indie game studio as a junior developer. Your lead developer has asked you to quickly
prototype a simple, playable 2D arcade-style game using Python. The catch? You are unfamiliar with the Pygame library,
and you need to complete the prototype within a short development sprint. Fortunately, your team encourages using
AI-powered tools like GitHub Copilot to boost productivity. Your task is to research, build, and enhance your game
entirely through conversation with GitHub Copilot.

## Directions
This activity has two parts. First, you will demonstrate your ability to use GitHub Copilot to research, prompt, generate, and refine code that meets functional requirements for a basic 2D game. Use GitHub Copilot to do the following:

## Research how to use the Pygame library
Generate code for each required feature of the game
Enhance code entirely through conversation
Request user instructions and code comments from the tool
Then, you will demonstrate the outcome of your interaction with GitHub Copilot in a screen recording or using screenshots. Your screen recording or screenshots should show that your final game is fully playable and meets the following requirements.

## Game Requirements

- The game is built using the Pygame Python library.
- It includes simple (circles, squares, etc.) 2D graphics (generated by Pygame) and keyboard input to control on-screen elements.
- It contains a challenge mechanic (e.g., enemy, time limit).
- It implements a scoring system visible on the screen.
- It provides on-screen player instructions.
- It is stable and playable with basic win/loss or gameplay conditions.

Note: You must not write or fix code manually—your chat log should reflect the complete process from research through debugging using the AI tool.

## Specifically, you must address the following rubric criteria:

### Part One: AI Chat Log

- Construct an initial prompt that communicates the functional requirements of the game.
- Revise the prompt iteratively based on AI feedback to enhance output.

### Part Two: Screen Recording or Screenshots

- Demonstrate a functional game that includes 2D graphics, keyboard controls, and a visible scoring system.
- Showcase a challenge mechanic (e.g., enemy behavior or timer) and on-screen player instructions.
